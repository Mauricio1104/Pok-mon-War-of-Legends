# Tilesets de referência (baixados, ainda não integrados)

Pacotes puxados de [Team Aqua's Asset Repo](https://github.com/TeamAquasHideout/Team-Aquas-Asset-Repo) (gratuito pra uso e edição em hacks de decomp Gen 3, ver `README.md` do repositório original — cada pasta abaixo tem seu próprio `credits.md`/`README.md` com os criadores originais, mantido junto).

**Status: só baixado.** Nenhum desses tilesets está registrado no `porymap.project.cfg` nem em `data/layouts/layouts.json` ainda — isso é feito via Porymap (`Tools → New Tileset`) quando formos de fato construir os mapas de Amaranto/Bromélia.

| Pasta | Uso pretendido |
|---|---|
| `Autumn Ruins Secondary` | Amaranto — folhagem outonal + ruínas, tema "vales/cânions/tradições profundas" |
| `Volcano Secondary` | Bromélia — Vulcão Carmesim |
| `Valencia Island` | Bromélia — ilhas tropicais |
| `Desert Primary` | Amaranto — base rochosa/cânion, complemento |
| `Caves Alt Primary` / `Caves Alt Secondary` | Cavernas/dungeons opcionais de qualquer região |

Ver [design/cidades.md](cidades.md) pra que cidade cada tema se aplica.
